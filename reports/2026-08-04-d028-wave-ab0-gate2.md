## Mục 2 — Đối chiếu SQL độc lập (QC tự viết, **luật khác** worker)

Cố ý **không** dùng lại mẫu `%ala%` / `%ọa đàm%` của worker — nếu mẫu đó sai thì dùng lại nó sẽ sai giống hệt và vẫn ra "0 lệch". Tag khớp bằng `= ANY(string_to_array(...))`, form khớp bằng regexp có biên từ:

```sql
WITH g AS (
  SELECT gu.id, string_to_array(coalesce(gu.tags,''),',') AS tagarr,
         lower(coalesce(s.sessions,'')) AS sess
  FROM crm_guests gu LEFT JOIN rsvp_submissions s ON s.id = gu.response_id
  WHERE gu.deleted_at IS NULL)
SELECT count(*) FILTER (WHERE 'gala' = ANY(tagarr)
         OR sess ~ '(^|[^[:alnum:]])gala([^[:alnum:]]|$)')     AS union_gala,
       count(*) FILTER (WHERE 'toa-dam' = ANY(tagarr)
         OR sess ~ 'tọa đàm|toa dam|toa-dam')                  AS union_toa
FROM g;
```

```
total 376 | tag_gala 303 | tag_toa 149 | form_gala 47 | form_toa 7
union_gala 350 | union_toa 156          →  ±0 so với API
```

**Chưa dừng ở tổng — so tới từng ID.** Hai tập có thể cùng kích thước mà khác người; `array_agg(id)` từ SQL đối chiếu với `id` API trả về:

```
?session=gala   : api=350 sql=350 | chỉ-API=0 chỉ-SQL=0 → SET BẰNG NHAU
?session=toa-dam: api=156 sql=156 | chỉ-API=0 chỉ-SQL=0 → SET BẰNG NHAU
du_gala (tab)   : api=350 sql=350 | chỉ-API=0 chỉ-SQL=0 → SET BẰNG NHAU
du_toa_dam (tab): api=156 sql=156 | chỉ-API=0 chỉ-SQL=0 → SET BẰNG NHAU
```

Kiểm bổ sung: `response_id` mồ côi (trỏ tới submission không tồn tại) = **0** — không có khách nào rơi im lặng qua `EXISTS`.

✅ **±0, ở mức tập hợp chứ không phải mức tổng.**

## L1 — **BLOCKER** · nav mới đẩy 日本語 / sáng-tối / `⋯` (kể cả **Đăng xuất**) ra ngoài màn điện thoại

**Vì sao là blocker chứ không phải cosmetic:**

1. Nút mất gồm **đổi sang tiếng Nhật** — thứ mà chính AC-B0 yêu cầu («i18n vn/jp») và là đường duy nhất của PG Nhật.

```css
@media(max-width:520px){
  .top-in{flex-wrap:wrap}
  .cknav{order:9;flex-basis:100%;margin-left:0;justify-content:center}
}
```

hoặc bỏ `.cknav` khỏi header ở mobile và đưa 2 lối đi vào đầu ngăn `⋯`. Cách nào cũng phải đo lại `scrollWidth === clientWidth` ở **390 / 360 / 320**.
