## 2. Đường lùi — vì sao deploy trước backfill là an toàn

`thumb_key` NULL ⇒ route `/thumb` **302 về ảnh gốc**, tức đúng hành vi trước vé. Đo trên prod
ngay sau deploy (chưa có thumb nào):

```
(gốc)    → HTTP 302     theo redirect → 200 · image/jpeg · 61 KB
/thumb   → HTTP 302     không đăng nhập → 401 ✅
/preview → HTTP 302
```

Nhờ vậy backfill dừng giữa chừng cũng không màn nào mất ảnh — xấu nhất là **chậm như hôm nay**.
