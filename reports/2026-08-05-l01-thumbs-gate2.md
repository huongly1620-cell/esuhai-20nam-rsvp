## 2. Dải `.thumbs` — ảnh quà khác ảnh chân dung

| | Ô **ảnh quà** | Ô **ảnh chân dung** |
|---|---|---|
| class bọc | `th1 **qua** landscape` | `th1 landscape` |
| viền ảnh | **2px** `rgb(242, 183, 78)` (hổ phách) | 1px `rgba(224, 189, 119, 0.16)` |
| nhãn | **có** — ký tự **🎁**, `display:block`, `visibility:visible`, `opacity:1` | **không** |
| tooltip (`title`) | «Ảnh quà / ghi nhận tại quầy» | *(không có)* |
| nhãn nằm trong màn | ✅ | — |
| `elementFromPoint` giữa nhãn | **trả về chính nhãn** ⇒ hiện thật, không bị đè/cắt | — |

Kết quả **giống hệt** ở cả bốn tổ hợp:

| | `.th1` bọc | `<img>` trần còn sót | Ô có nhãn | Lỗi JS |
